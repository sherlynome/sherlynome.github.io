万象盒 · AllBox 技术说明

这是一个纯前端单文件的 3D 展示器：无需后端、无需打包，用 Three.js 即可在网页里展示 3D 内容。

两种内容

  • 高斯泼溅（Gaussian Splatting）：用成千上万个带颜色与透明度的高斯椭球表达真实场景，渲染时按视角累积成连续、可自由环绕的影像——比传统网格更真实，且无需建模。
  • 低多边形场景（low-poly）：用 Three.js 几何体程序化生成的萌系小世界，flat shading 呈现硬边质感；其中「夜晚小镇 / 卡通农场 / 夜晚便利店 / 富士山7-Eleven」带动态效果（星空闪烁、风车旋转、樱吹雪、小车驶过等）。

技术栈

Three.js (r171) + @mkkellogg/gaussian-splats-3d；通过 importmap 从 CDN 加载，零构建。泼溅场景与网格场景相互隔离、独立渲染，切换不互相干扰。

加载你自己的模型

  • 建模作品（Nomad / Blender）：导出 .glb，直接拖到页面任意位置即可展示（已自动补灯光与材质）。
  • 训练好的高斯泼溅：.ply / .splat / .ksplat 同样可拖入，或粘贴 URL 加载。

运行须知

需经 HTTP 托管打开（勿直接双击 file://）；浏览器需支持 WebGL。顶部「电脑端 / 手机端」可切换不同展示比例预览。
